# Abhay's Personal Portfolio

Hey! I'm Abhay, a 10th grader who builds software and hardware projects and plays a lot of table tennis. I made this personal website to introduce myself to the Hack Club community, share what I'm currently working on, and keep track of my goals.

## What's on the site
- **About Me:** A quick intro, my coding skills, and a bit about table tennis.
- **Current Work:** My IED tutorial breaking down how breadboards, wires, and resistors work together.
- **Past Projects:** Links to my 3D Chess game on itch.io and a couple of older Scratch games, plus a demo video.
- **Goals:** My plan to ship enough projects through Hack Club to earn a faster laptop and a 3D printer for hardware builds.

## Tech Used
- HTML5 & CSS3

## Note on Using This Code
Feel free to look through the code for inspiration or layout ideas if you're building your own Hack Club portfolio, but please don't copy-paste the whole site as your own.
